# How to download Bootstrap for local development

Go to the [Bootstrap GitHub repository releases tab](https://github.com/twbs/bootstrap/releases) and find the [release matching this folder name](https://github.com/twbs/bootstrap/releases/tag/v5.3.3).

From there, download the [source code archive](https://github.com/twbs/bootstrap/archive/refs/tags/v5.3.3.zip) from the Assets section and extract it into this folder.

Delete everything except the `scss` and `js` folders in the root.
